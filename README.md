# Justin Leonard

UX and product designer for AI-enabled tools and products. I design from the first research question to screens people can click, and I build with an AI-assisted workflow.

**Portfolio:** [vyztra.github.io/portfolio/ux.html](https://vyztra.github.io/portfolio/ux.html)

## How I work

- **Measure first.** Crawl it, time it, count the taps, then design.
- **Show before code.** Mockups and a yes before anything gets built.
- **I don't grade my own work.** Hostile reviews, back-tests and playtests written down word for word.
- **Label what's proven.** Every case study says what it can prove and what it can't yet.
